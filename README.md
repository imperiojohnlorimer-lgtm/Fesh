# Fesh

A pixel-art fishing mystery game for Windows, written in C# with [Raylib-cs](https://github.com/raylib-cs/raylib-cs).
Catch strange creatures around Saltmere Island and find out how they got there, while you explore five islands, fish
with power casts, bait and tackle, take on legendary fish, explore a twelve-floor cave, build, craft and cook.

The game lives in [`fesh-csharp/`](fesh-csharp). See its [README](fesh-csharp/README.md) for how to play, build and
install it.
